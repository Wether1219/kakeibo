# 家計簿Webアプリ 要件定義書

- 版数：v0.1（ドラフト）
- 作成日：2026-08-13
- 元資料：`雛形_家計簿_第1_4版_.xlsm`（第1.4版）

---

## 1. はじめに

### 1.1 目的
現在Excel（マクロ有効ブック）で運用している2人世帯向け家計簿を、Webアプリケーション（VS Code + MySQL + GitHub、AIによるバイブコーディング開発）としてリプレイスする。本書は、現行Excelブックの機能・構造を分析した結果をもとに、新システムに求める要件を定義する。

### 1.2 現行Excelブックの課題（システム化の狙い）
| # | 課題 | システム化による解決 |
|---|---|---|
| 1 | 複数端末・複数人での同時編集ができない（ファイル競合） | Webアプリ化しDB一元管理、いつでもどこでも入力可能 |
| 2 | 年が変わるたびにマクロで年切替・シート複製が必要 | 年月はデータ属性として保持し、切替操作を不要化 |
| 3 | セル参照・SUMIFSの数式が複雑で壊れやすい（実際に費目名の文字化け `_xDCDC_📜保険` が発生済み） | 集計をアプリ/DBロジック化し、数式破損リスクを排除 |
| 4 | スマホから入力しづらい | レスポンシブUI、スマホでの支出入力を主要ユースケースとする |
| 5 | 費目マスタ変更時に全シート（12ヶ月分）を手修正 | 費目マスタをDBで一元管理し、全画面に即時反映 |
| 6 | バックアップ・変更履歴がファイルコピー任せ | DB管理＋Git管理＋アプリ内変更履歴で担保 |

### 1.3 対象読者
開発者本人（AIコーディングエージェントへの指示のインプットとしても使用）。

## 2. 現行Excelブック機能分析（現行業務把握）

### 2.1 シート構成と役割
| シート名 | 役割 |
|---|---|
| 変更履歴 | バージョン管理台帳（版数・日付・変更内容） |
| 費目マスタ | 収入／先取り貯金・投資／固定費／変動費の費目タグ一覧（絵文字アイコン付き）。各月シートのプルダウン元 |
| 資産管理シート | 現金・預貯金／証券・株式／保険を、名称・名義（人）・用途単位で月末残高を記録。月次×人別×合計を自動集計 |
| 収支可視化シート | 月平均（毎月発生するもの）・年計（臨時発生するもの）を人別に集計し、支出率・貯蓄率をKPIとして表示（目標値：支出率60%以下／貯蓄率40%以上） |
| 年間推移 | 12ヶ月分の月次シートの数値を費目別に1行にまとめ、月次推移と年間合計を表示 |
| 27年1月〜27年12月（月次シート×12） | 収入・先取り貯金/投資・支出明細（取引台帳）・週次予算・固定費/変動費集計・当月収支・月間カレンダー・グラフを1シートに集約 |

### 2.2 月次シートの主要機能（現行の中核機能）
1. **年月設定＆カレンダー自動生成**：年・月を入力すると、当該月のカレンダー（日曜始まり、5〜6週）が自動生成される。
2. **収入入力**：給与／賞与／配当金／臨時収入／その他 × 人（2名）で入力。
3. **先取り貯金・投資入力**：貯金／NISA／投資／iDeCo × 人（2名）で、予算と実績（入力値）を管理。
4. **支出明細（取引台帳）入力**：日付／週（1〜5week自動判定）／人（本人 or 両方＝折半）／費目／金額／詳細を1行1取引で入力。全集計の元データ。
5. **週次予算管理**：変動費費目ごとに週（1〜5week）単位で予算と実績（SUMIFSで自動集計）を対比し、差分を表示。
6. **固定費集計（人別）**：光熱費・水道代・通信費・サブスク・奨学金・保険・住宅費を人別にSUMIFSで自動集計。「住宅」など両者共有費目は折半（÷2）。
7. **変動費集計（人別）**：食費・日用品・雑費・趣味娯楽・交際費・衣服美容・健康医療・交通費・ふるさと納税を人別に自動集計。「両方」区分の取引は折半して各人に加算。
8. **当月収支の算出**：収入(a) − 先取り貯金・投資(b) − 支出(c) ＝ 余り貯金(d)、貯蓄合計(e)＝b＋d、を人別に算出。
9. **グラフ**：固定費・変動費の費目別内訳（円グラフ等）を人別に自動生成。

## 3. システム化の目的

- 現行Excelの機能を過不足なくWebアプリで再現する（フェーズ1）。
- スマートフォンからの支出入力を主動線とし、入力のハードルを下げる。
- 2人（将来的には世帯人数可変）でのリアルタイムなデータ共有を実現する。
- 費目マスタ・予算・実績・資産をDBで一元管理し、数式破損や手修正漏れを撲滅する。
- 将来的な拡張（複数世帯対応、レシートOCR連携、CSV/Excelインポート等）に耐えるDB設計とする。

## 5. 機能要件

### 5.1 機能一覧（現行Excelとの対応）

| No | 機能カテゴリ | 機能名 | 概要 | 現行Excel対応箇所 |
|---|---|---|---|---|
| F01 | 認証 | ログイン／ログアウト | 世帯メンバー単位でログイン | なし（新規） |
| F02 | マスタ管理 | 費目マスタ管理 | 費目（収入/先取り貯金/固定費/変動費）の追加・編集・並び替え・無効化 | 費目マスタシート |
| F03 | 収支入力 | 取引（支出・収入）入力 | 日付・自分/相手/両方・費目・金額・メモを入力。「両方」選択で自動折半 | 各月シートT〜Y列 |
| F04 | 収支入力 | 収入入力 | 月次・費目・人別に収入を入力 | 各月シートB〜E列 |
| F05 | 収支入力 | 先取り貯金・投資入力 | 月次・費目・人別に予算/実績を入力 | 各月シートG〜J列 |
| F06 | 予算管理 | 週次予算設定・実績対比 | 変動費費目ごとに週単位で予算設定、実績は取引データから自動集計、差分表示 | 各月シートL〜R列 |
| F07 | 集計 | 月次固定費/変動費集計（人別） | 取引データから人別・費目別に自動集計。共有費目は折半 | 各月シートB22〜J40 |
| F08 | 集計 | 当月収支サマリ | 収入(a)−先取り貯金(b)−支出(c)＝余り貯金(d)、貯蓄合計(e)＝b+d を人別算出 | 各月シートB42〜J45 |
| F09 | 集計・可視化 | ダッシュボード（月次） | 費目別内訳グラフ、予算消化率、収支サマリを1画面で表示 | 各月シートのグラフ群 |
| F10 | 集計・可視化 | 年間推移 | 費目別×月別（1〜12月＋年間合計）の一覧・グラフ | 年間推移シート |

| F12 | 資産管理 | 資産管理（月末残高） | 現金・預貯金／証券・株式／保険を口座単位で月末残高入力、人別・総合計を自動集計、推移グラフ | 資産管理シート |
| F13 | 履歴 | 変更履歴／操作ログ | アプリ自体の版数管理、および家計データの編集履歴（誰がいつ何を変更したか） | 変更履歴シート＋新規要件 |

### 5.2 主要業務ルール（現行Excelの計算ロジックを踏襲）

- 取引の「対象者」は「本人（たいよう／みらの）」または「両方（折半）」を選択できる。「両方」の場合、集計時に金額を2で割って各人に按分する。折半時の端数（1円未満）は片方に寄せる等、業務ルールとして明文化する（現行v1.2の改善を踏襲）。
- 週次予算の「週」は月内の日付から自動判定する（日曜始まり、第1〜5週）。
- 固定費のうち「住宅」など明確に共有と分かる費目は、現行同様「両方」区分で折半計算する。
- 支出率・貯蓄率などの比率計算は、分母が0の場合にエラーとせず0またはハイフン表示とする（現行v1.4のIFERROR対応を踏襲）。
- 費目には絵文字アイコンを付与し、一覧・グラフの視認性を高める（現行踏襲、将来的にはアイコン選択制も検討）。

## 6. 非機能要件

| 分類 | 要件 |
|---|---|
| 性能 | 個人〜数世帯規模の利用を想定。月次集計・年間推移の表示は3秒以内を目安とする |
| セキュリティ | 家計・資産情報を扱うため、パスワードハッシュ化、HTTPS必須、世帯単位のデータ分離（他世帯のデータに一切アクセスできないこと）を必須とする |
| 可用性 | 個人利用のため常時稼働の厳密なSLAは設けないが、月次のデータ消失は許容しない（バックアップ必須） |
| ユーザビリティ | スマートフォンでの支出入力を3タップ以内で完了できることを目標とする |
| 保守性 | 費目・予算ロジックの変更をコード修正・マイグレーションのみで完結できること（Excel数式のような属人的修正を排除） |
| 移植性 | 将来的なクラウド移行（VPS/PaaS）を見据え、環境変数によるDB接続設定の外出し等、12-Factor的な構成とする |
| データバックアップ | MySQLの定期ダンプ、およびGitHubへの構成管理（コードのみ、個人情報は含めない） |

## 8. スコープ外（初期リリースでは対象外とする事項）

- レシートOCRによる自動入力
- 銀行口座・クレジットカードとの自動連携（API連携）
- 3世帯以上の同時運用を前提としたマルチテナント基盤（設計上は考慮するが実装は世帯数=1〜少数を想定）
- ネイティブスマホアプリ化（初期はレスポンシブWebのみ）

## 9. 用語集

| 用語 | 説明 |
|---|---|
| 費目（ひもく） | 収入・支出の分類タグ（例：食費、光熱費） |
| 先取り貯金・投資 | 収入から支出前にあらかじめ確保する貯金・投資額 |
| 両方（折半） | 夫婦・世帯2名で共有する支出。集計時に金額を2で割って按分する |
| 固定費 | 毎月ほぼ一定額発生する費用（光熱費、通信費、住宅費等） |
| 変動費 | 月により金額が変動する費用（食費、娯楽費等） |
| 支出率 | 支出(c) ÷ 収入(a) × 100 |
| 貯蓄率 | 貯蓄合計(e) ÷ 収入(a) × 100 |
