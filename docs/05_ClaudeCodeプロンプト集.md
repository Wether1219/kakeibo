# Claude Code フェーズ別プロンプト集

## 使い方
1. `CLAUDE.md` をリポジトリルートに配置し、`docs/`配下に01〜04のドキュメントを格納した状態でClaude Codeを起動する（CLAUDE.mdは自動読込されるため、以下のプロンプトでは技術スタックや規約の再説明をしていない）。
2. 各フェーズは複数のプロンプトに分割している。**1プロンプト＝1機能ずつ実行し、完了して動作確認できたら `/clear` してからコンテキストをリセットして次に進む。** これによりセッションが肥大化してトークンを浪費するのを防ぐ。
3. 各プロンプトはあえて「該当節のみ読め」と指定している。詳細設計書全体を読ませないことがトークン削減の最大のポイント。

## 補足：さらにトークンを抑えたい場合
- 1機能内でもフロント/バックを分けたい場合は、上記プロンプトを「まずバックエンドのみ」「続けてフロントのみ」と2回に分割する
- 大きめの機能（1-4, 3-2）は特にコンテキストが膨らみやすいため、実装計画提示の段階で `/clear` を挟んでから実装フェーズに入ってもよい
- ドキュメント自体を頻繁に更新した場合は、該当箇所の行番号や節番号をプロンプトに追記すると、Claude Codeが探索コストなく該当箇所だけ読める
