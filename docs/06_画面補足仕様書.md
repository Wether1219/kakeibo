## SC02 ダッシュボード（月次）

### レイアウト構成（上から順に配置）

```
┌─────────────────────────────────────────┐
│ [◀ 2027年1月 ▶]  年月セレクタ           │
├──────────────┬──────────────────────────┤
│ 収支サマリ    │ 収支サマリ               │
│（たいよう）   │（みらの）                │
│ 収入(a)    ¥xx│ 収入(a)    ¥xx           │
│ 先取り(b)  ¥xx│ 先取り(b)  ¥xx           │
│ 支出(c)    ¥xx│ 支出(c)    ¥xx           │
│ 余り(d)    ¥xx│ 余り(d)    ¥xx           │
│ 貯蓄計(e)  ¥xx│ 貯蓄計(e)  ¥xx           │
├──────────────┴──────────────────────────┤
│ 支出内訳 [たいよう|みらの] タブ切替       │
│ ┌──────────┐ ┌──────────┐               │
│ │ 固定費   │ │ 変動費   │               │
│ │ 円グラフ │ │ 円グラフ │               │
│ └──────────┘ └──────────┘               │
├─────────────────────────────────────────┤
│ 週次予算 消化状況                        │
│ 🍙食費    ████████░░ ¥12,000/¥15,000    │
│ 🧴日用品  ██████░░░░ ¥3,000/¥5,000      │
│ ...                                     │
├─────────────────────────────────────────┤
│ 直近取引 (最新10件)                      │
│ 8/13 🍙食費 たいよう ¥1,200 スーパー     │
│ 8/12 🚃交通費 みらの ¥500               │
│ ...                         [もっと見る] │
└─────────────────────────────────────────┘
```

### コンポーネント分割

| コンポーネント名 | 責務 |
|---|---|
| `MonthSelector` | 年月の前後切替。変更時に親へ `{year, month}` を通知 |
| `BalanceSummaryCard` | 1人分の収支サマリカード。props: `{displayName, income, preSaving, expense, remainingSaving, totalSaving}` |
| `ExpensePieCharts` | タブ切替（人別）＋固定費/変動費の2つの円グラフ。Chart.js Doughnut使用 |
| `WeeklyBudgetProgress` | 変動費費目ごとの進捗バー。予算=0の費目は非表示 |
| `RecentTransactions` | 直近取引リスト。「もっと見る」でSC04へ遷移 |

### 使用API

| API | 用途 |
|---|---|
| `GET /summary/monthly?year=&month=` | 収支サマリ・費目別集計（レスポンス形式は `docs/03 4.1` 参照） |
| `GET /weekly-budgets?year=&month=` | 週次予算＋実績 |
| `GET /transactions?year=&month=&limit=10&sort=date_desc` | 直近取引 |

### グラフ仕様

| グラフ | 種類 | データ | 色 |
|---|---|---|---|
| 固定費内訳 | Doughnut | 費目別合計（7費目） | 費目ごとに固定色パレット |
| 変動費内訳 | Doughnut | 費目別合計（9費目） | 同上 |

### レスポンシブ

- PC: 収支サマリ2カラム横並び、円グラフ2つ横並び
- スマホ: すべて1カラム縦積み

### コンポーネント分割

| コンポーネント名 | 責務 |
|---|---|
| `YearSelector` | 年の前後切替 |

| API | 用途 |

| `GET /summary/annual?year=` | 全費目×12ヶ月の集計データ |

```
┌─────────────────────────────────────────┐
│ [◀ 2027年 ▶]  年セレクタ                │
```

### コンポーネント分割

| コンポーネント名 | 責務 |
|---|---|
| `YearSelector` | SC07と共通化 |
| `AverageBalanceSection` | 月平均収支を人別で表示 |
| `AnnualBalanceSection` | 年間収支（臨時含む）を人別で表示 |
| `KpiCards` | 支出率・貯蓄率を人別にカード表示。閾値判定で色分け（🟢60%以下/🔴超過、🟢40%以上/🔴未達） |
| `RatioTrendChart` | 月別の支出率・貯蓄率推移＋目標線。Chart.js Line使用 |

### 使用API

| API | 用途 |
|---|---|
| `GET /summary/visualization?year=` | 月平均/年計の収支、人別KPI |

### APIレスポンス形式（補足）

```json
{
  "year": 2027,
  "members": [
    {
      "userId": 1,
      "displayName": "たいよう",
      "monthlyAverage": {
        "income": 300000, "preSaving": 50000, "expense": 140000,
        "remainingSaving": 110000, "totalSaving": 160000
      },
      "annual": {
        "income": 3800000, "preSaving": 600000, "expense": 1700000,
        "remainingSaving": 1500000, "totalSaving": 2100000
      },
      "expenseRatio": 55.0,
      "savingRatio": 45.0,
      "monthlyRatios": [
        {"month": 1, "expenseRatio": 50.0, "savingRatio": 50.0},
        {"month": 2, "expenseRatio": 58.0, "savingRatio": 42.0}
      ]
    }
  ]
}
```

### KPI閾値ルール

| 指標 | 🟢良好 | 🔴要改善 |
|---|---|---|
| 支出率 | ≤ 60% | > 60% |
| 貯蓄率 | ≥ 40% | < 40% |
| 分母0（収入なし） | 「-」表示、色なし | |

## SC09 資産管理画面

### レイアウト構成

```
┌─────────────────────────────────────────┐
│ [◀ 2027年 ▶]  年セレクタ                │
├─────────────────────────────────────────┤
│ [現金・預貯金|証券・株式|保険] タブ切替    │
├─────────────────────────────────────────┤
│ 口座一覧＋月末残高入力テーブル            │
│ 名称        │名義  │1月  │2月 │...│12月│
│ 三井住友銀行│太    │[   ]│[  ]│   │[  ]│
│ ゆうちょ銀行│太    │[   ]│[  ]│   │[  ]│
│ 三菱UFJ銀行│み    │[   ]│[  ]│   │[  ]│
│ ...         │      │     │    │   │    │
│ たいよう計  │      │ xxx │xxx │   │xxx │
│ みらの計    │      │ xxx │xxx │   │xxx │
│ 合計        │      │ xxx │xxx │   │xxx │
│                              [＋口座追加]│
├─────────────────────────────────────────┤
│ 資産推移グラフ（積み上げ面/棒グラフ）     │
│ ┌───────────────────────────────┐        │
│ │ ███ 現金預貯金                │        │
│ │ ███ 証券・株式                │        │
│ │ ███ 保険                     │        │
│ │ 1  2  3  4  5 ... 12          │        │
│ └───────────────────────────────┘        │
└─────────────────────────────────────────┘
```

### コンポーネント分割

| コンポーネント名 | 責務 |
|---|---|
| `YearSelector` | SC07/SC08と共通化 |
| `AssetGroupTab` | 現金預貯金/証券株式/保険のタブ切替 |
| `AssetBalanceTable` | 口座×12ヶ月のマトリクス入力。セル編集→即API保存（デバウンス500ms）。人別小計・合計行は自動計算表示 |
| `AddAssetModal` | 口座追加モーダル（名称/名義/詳細/用途/積立額） |
| `AssetTrendChart` | 3グループの月次推移。Chart.js Stacked Bar or Area使用 |

### 使用API

| API | 用途 |
|---|---|
| `GET /assets?assetGroup=` | 口座一覧 |
| `POST /assets` | 口座追加 |
| `PUT /assets/:id` | 口座編集 |
| `GET /asset-balances?year=` | 月末残高一覧 |
| `PUT /asset-balances/bulk` | 月末残高一括保存 |

### 入力UX

- テーブルセルは直接クリック→数値入力可（Excelライクなインラインエディット）
- 入力確定（blur/Enter）でデバウンスAPI呼び出し。保存中はセルにスピナー表示
- 横スクロール対応（スマホでは名称列を固定、月列をスクロール）
