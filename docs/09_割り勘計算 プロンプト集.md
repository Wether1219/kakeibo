# Claude Code プロンプト集（割り勘計算機能 F16）

## 使い方

1. `docs/08_割り勘計算_仕様書.md` を `docs/` に配置済みであること
2. 下記フェーズG-1〜G-6を順に実行。1つ完了→動作確認→ `/clear` →次へ
3. **Excelファイル本体をClaude Codeに読ませないこと**（解析済みの結果が08に全て記載されているため。xlsmを読ませると解析だけで数万トークン消費する）

### トークン削減のポイント
- Excel解析は完了済み。08の該当セクションのみ読ませれば実装可能
- DB→ロジック→API→フロント の4分割で、各セッションのコンテキストを最小化
- 計算ロジック（G-2）だけは仕様の精度が重要なため08の3章を丸ごと読ませるが、それ以外は1セクションのみ
- 疑似コードを08に記載済みなので、Claude Codeに設計を考えさせない＝往復回数を削減

## フェーズG-2：精算計算ロジック（最重要）

```
docs/08_割り勘計算_仕様書.md の「3. 精算ロジック」セクションのみ読んで。

backend/src/services/settlementService.ts を新規作成し、
3.1の疑似コードに厳密に従って calculateSettlement() を実装して。

重要な注意点:
- 3.2の端数処理ルールを厳守（取引ごとに丸めず、最終合計のみMath.round）
- 既存の按分ロジック(split_type)とは完全に独立させること。費目集計に影響を与えない

単体テストを必ず先に書いて。テストケースは最低限以下を含めること:
1. ☀のみ(折半・A払い) 2件
2. ☆のみ(折半・B払い) 2件
3. ♠♡混在(全額相手負担)
4. 4パターン全混在
5. 半端額(partial)ありのケース
6. 金額が奇数円で端数が発生するケース
7. 対象取引0件 → direction NONE
8. netAがちょうど0 → direction NONE

まず実装計画とテストケース一覧を提示して。承認後に実装して。
```
